# Documents Module Plugin

This plugin registers the Documents module with the Vue application.

## Features

- Document management (CRUD operations)
- File upload and download
- Share links with security options
- Metadata templates
- Bulk operations
- Access logging
- Statistics and analytics

## Installation

The plugin is automatically installed when the Documents module is imported.

## Usage

```typescript
import DocumentsPlugin from '@/plugins/documents'

app.use(DocumentsPlugin)
```

## Dependencies

- Vue 3
- Vue Router
- Pinia
- Vuetify
- TypeScript
